# Excel-Sales-Dashboard-Portfolio
Sales and Profit Analysis Dashboard Created in Excel Using Slicers and Multiple Charts.

## Project Overview

This project analyzes retail sales data (downloaded from kaggle database) using Microsoft Excel .

## Tools Used

* Excel Pivot Tables
* Pivot Charts
* Slicers
* Data Cleaning

## Insights Generated

* Regional sales comparison
* Profit by segment
* products giving highest and lowest profits
* Impact of discount on profit
* Category performance analysis
